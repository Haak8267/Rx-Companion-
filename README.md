# Rx Companion

A pharmaceutical information and medication-support assistant application.

## Getting Started

### Prerequisites
- Node.js >= 24.0.0
- npm

### Installation
```bash
npm install
```

### Configuration
Create or configure `.env` with your API keys:
```env
OPENROUTER_API_KEY=your_key_here
PORT=3000
```

### Running the Application
To start the development server:
```bash
npm run dev
```

The application will be accessible at:
```
http://localhost:3000
```

## Features
- **Instant Consultation:** AI-assisted drug information, interactions, pill identification, and medication schedules.
- **Medication Records:** View and update patient medication lists.
- **Patient Facts & Household Profile:** Manage durable patient context, preferences, and caregiver details.
- **Health Check:** Live status indicator verifying backend readiness.
